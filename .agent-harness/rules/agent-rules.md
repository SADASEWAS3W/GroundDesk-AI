# Agent 规则

- Agent 只能通过已注册工具或注入的服务接口访问外部状态。
- 工具名称、Prompt 引用、参数 Schema 和测试必须同步。
- 工具结果必须结构化、限制大小，并确保可以安全发送给模型。
- 工具失败不得被转换成虚假的成功回答。
- 退款、法律、销户等破坏性操作、证据不足或 Grounding 失败必须进入人工审核。
- 人工审核必须支持恢复和幂等；重复批准不得重复产生副作用。
- 模型供应商必须集中配置，工具和 API 路由中不得自行创建客户端。
- 未明确配置和授权时，关闭供应商托管的 tracing。
- 每个 Graph 节点必须说明输入、输出、失败状态和下一步路由条件。
- Prompt、工具协议、路由或审核策略变化默认属于 L3。
