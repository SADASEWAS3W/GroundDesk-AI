# RAG 规则

- 查询向量和文档向量必须使用相同模型、维度、归一化规则和语义空间。
- 当前数据库契约为 PostgreSQL `VECTOR(1536)`。
- 每次 Embedding 请求必须显式请求并校验 1536 维。
- 更换 Embedding 模型必须包含全量重建、缓存版本升级和回滚方案。
- 文档进入重排前必须具有稳定 ID、标题、正文、来源元数据和分数。
- Citation 只能引用当前检索流程真实返回的文档。
- 没有有效证据的回答不得标记为 Grounded，也不得直接发送给客户。
- Vector、BM25、融合和 Reranker 必须拥有独立接口和测试。
- 检索阈值必须由评测数据确定，不能直接沿用其他模型的阈值。
- 检索修改至少提供 Recall@3、MRR、失败案例和基线对比。
