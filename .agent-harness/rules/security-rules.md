# 安全规则

- 禁止提交 `.env`、API Key、Token、密码、客户导出、数据库备份或包含隐私数据的 Prompt。
- 密钥只能通过服务端环境变量、Compose Secret 或 Kubernetes Secret 注入。
- `NEXT_PUBLIC_*` 变量不得包含任何凭据。
- 日志不得记录认证头、完整密钥或非必要个人数据。
- 模型和工具输入只能包含完成当前操作所需的最少客户上下文。
- SQL 值必须参数化；动态 SQL 标识符必须使用白名单。
- 破坏性操作必须验证精确目标、获得明确授权并提供恢复方案。
- 高风险模型操作必须经过确定性策略检查或人工审核。
- 安全相关依赖或部署变化属于 L3。
